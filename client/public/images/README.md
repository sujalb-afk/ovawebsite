# Images

To use original OVA website images, download them from https://www.ova.ngo/ and place here.

**Hero slideshow (homepage):** For the four hero slides to show, add these files:
- In **client/public/images/hero/**: `herobg1.png`, `herobg3.png`, `herobg4.png`
- In **client/public/images/**: `hero-skills.png`

Suggested structure:
- ova-logo.png - OVA logo for navbar and footer (production)
- ova-logo-test.png - Test logo for navbar (used when testing a new logo; see Navbar.js)
- logo.png - OVA logo for navbar
- hero-skills.png - Hero slide 2 image (career/skills)
- team/ - Team member photos
- gallery/ - Gallery images

The app uses placeholder/fallback when images fail to load.
